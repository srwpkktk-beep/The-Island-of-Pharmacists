# ร้านยาของฉัน เกาะญี่ปุ่น (เล่นด้วยกันผ่าน GitHub Pages)

เกมนี้เป็นไฟล์ `index.html` ไฟล์เดียว โฮสต์ฟรีบน GitHub Pages ได้ เพื่อนเปิดลิงก์แล้วเล่นได้เลย **ไม่ต้องล็อกอิน Claude**

## วิธีขึ้นเว็บ (ทำครั้งเดียว)

1. เข้า github.com แล้วกด **New repository** ตั้งชื่อ เช่น `pharmacy-island` เลือก **Public** แล้วกด Create
2. กด **Add file → Upload files** ลากไฟล์ `index.html` และ `.nojekyll` (ถ้ามี) ขึ้นไป แล้วกด **Commit changes**
3. ไปที่ **Settings → Pages**
4. ใต้ **Build and deployment** เลือก Source = **Deploy from a branch** เลือก Branch = `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
5. รอประมาณ 1-2 นาที แล้วเปิดลิงก์ `https://ชื่อผู้ใช้.github.io/pharmacy-island/`

ส่งลิงก์นี้ให้เพื่อนได้เลย

## วิธีเล่นด้วยกัน

1. ทุกคนเปิดลิงก์เกม แล้วไปที่แท็บ **เกาะ**
2. คนแรกกด **สร้างห้อง** ตั้งรหัส 4-6 ตัว (ตัวอักษรพิมพ์ใหญ่ผสมตัวเลข เช่น `K7P2Q`) หรือกด **สุ่มรหัส** แล้วรอจนขึ้นว่าเข้าห้องแล้ว
3. บอกรหัสให้เพื่อน เพื่อนกด **เข้าร่วมห้อง** แล้วใส่รหัส (ห้องรับได้สูงสุด 6 คน)
4. แตะบ้านเพื่อนบนเกาะ เพื่อเยี่ยมชม (ซูมดูหน้าร้านได้), บริจาคของที่เขาต้องการ, หรือท้าประลอง ผู้ชนะได้ 5 แต้ม

## ข้อควรรู้

- การเชื่อมต่อใช้ WebRTC ผ่านตัวกลางสาธารณะของ PeerJS (ฟรี แต่ไม่รับประกันความเสถียร)
- **คนสร้างห้องคือ host** ถ้า host ปิดหน้าเกม ห้องจะหายและทุกคนต้องสร้างห้องใหม่
- เครือข่ายบางแบบ (Wi-Fi องค์กร/โรงเรียน หรือเครือข่ายมือถือบางเจ้า) อาจเชื่อมต่อตรงกันไม่ได้ เพราะเวอร์ชันนี้ไม่มีเซิร์ฟเวอร์ TURN ลองเปลี่ยนเครือข่ายหรือให้เพื่อนเป็นคนสร้างห้อง
- รหัสห้องเป็นแค่กุญแจเข้าห้อง ไม่ใช่รหัสผ่านลับ ใครที่เดารหัสถูกก็เข้าได้
- ความคืบหน้าเกมบันทึกในเบราว์เซอร์ของแต่ละคน ถ้าล้างข้อมูลเบราว์เซอร์ เซฟจะหาย
